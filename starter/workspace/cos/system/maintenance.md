# Bounded maintenance entrypoint

For manual bounded maintenance, use the canonical [evening review contract](jobs/evening-review.md), [job configuration shape](jobs/job-config.template.md), and [learning loop](learning-loop.md). Fill the applicable scope and allowances before work; a manual invocation does not bypass per-task authority.

This is a pointer, not a second copy of the job's rules. No scheduler is installed, and no unattended run is enabled here.
