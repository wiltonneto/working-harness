# Daily artifacts

Use [the daily template](../templates/daily.md) for the brief and coordination spine. Date filled files with the configured local date. Keep dated maintenance outputs separate. No scheduler runs here.

Optional external [job contracts](../system/jobs/README.md) produce distinct evening-review, research-summary, and morning-compile artifacts here. Include run ID and state; the runner owns [the run ledger](../logs/job-runs.md). Keep detailed research under research and link it from the morning digest. Empty output directories mean no operating history has been supplied, not that jobs have already run successfully.
